# University Student Information Portal

A static student information portal for Masinde Muliro University of Science and Technology. The site presents sample student records, academic programmes, a student registration form, and an interactive grade calculator.

## Student records

The student directory in `index.html` displays student name, registration number, programme, and year of study. Student ID is intentionally excluded from the displayed table.

## Files

- `index.html` — portal content and student directory.
- `style.css` — page styling and responsive layout.
- `script.js` — registration interactions and grade calculator.

## Run locally

Open `index.html` in a modern web browser. No build step is required.
